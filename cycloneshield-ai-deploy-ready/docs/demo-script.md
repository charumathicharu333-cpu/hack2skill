# 3–5 minute demo script (target 4 minutes)

1. **0:00–0:25** Introduce CYCLONEShield AI and call out the persistent DEMO / PROTOTYPE DATA label. State it is not an official forecast.
2. **0:25–0:55** Show the illustrative Bay of Bengal track, time markers, wind and pressure values; select Nagapattinam on map or priority list.
3. **0:55–1:35** Walk through impact, infrastructure, population exposure and composite risk. Emphasize no exposed-population count is fabricated and every location feature is synthetic.
4. **1:35–2:05** Show the preparedness queue and how area selection updates the profile. Suggestions are considerations, not orders.
5. **2:05–2:50** Raise wind and rainfall in Scenario Lab. Click recalculate and show the score changes because engine inputs changed.
6. **2:50–3:25** Ask for an explanation. With a key, demonstrate Gemini; without it, show clearly labeled fallback. Explain Gemini does not set scores.
7. **3:25–4:00** Close with scale pathway: replace demo geographic features with licensed GEE/IMD/OSM/elevation/population sources, validate by historical events, then pilot with local authorities before any alerts.

Run backend and frontend per README. Optional: set `GEMINI_API_KEY` server-side. No recording is included.
