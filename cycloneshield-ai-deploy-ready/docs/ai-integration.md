# Google AI integration

`POST /api/ai/explain` accepts already calculated structured scores plus a requested language (English, Tamil, Hindi). With `GEMINI_API_KEY`, the server calls the Google Generative Language API and directs the model to explain only supplied values, not forecast or introduce new numbers. Numerical scores are never generated by Gemini. The key remains server-side and is not bundled in frontend code. Configure `GEMINI_MODEL` as needed; `.env.example` shows the expected variables.

If the API key is absent or the service errors, the API returns a transparent deterministic explanation labeled `Demo explanation (Gemini not configured)`. The current API checks shape, but a production deployment should use strict schemas, rate limits, logging with privacy controls, prompt-injection hardening, output moderation, multilingual quality review, and verified source references.

The event brief specifically names Gemini 3.7 Flash multimodal reasoning. No such model is assumed to be available here; the connector defaults to `gemini-2.0-flash` and may require changing to a currently supported model in the user's Google AI project. No image/multimodal or GEE integration is claimed.
