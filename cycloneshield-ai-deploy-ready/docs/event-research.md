# Official challenge research

Official event: **Build with AI: Code for Communities — Second Edition**, Google Cloud hackathon. Official page: https://hack2skill.com/event/codeforcommunities2 (read in browser on 2026-09-29).

Selected Problem 05: **Track-Based Cyclone Impact & Infrastructure Vulnerability Forecaster**, theme **Resilience**. The brief calls for anticipatory action for Bay of Bengal/coastal APAC using Google Earth Engine satellite feeds, real-time meteorology and Gemini 3.7 Flash multimodal reasoning; storm-surge simulation, local rainfall damage pathways, critical infrastructure exposure (power grids, arterial roads, medical shelters), and automated early-warning advisory dispatches to municipal/disaster authorities.

The official page says build a working prototype with end-to-end core functionality, mandatory Google AI integration, real or realistic data, India-scale design, and multilingual/voice support where the track calls for it. Recommended technologies include Gemini API/AI Studio/Vertex AI, GEE/Google Maps, Cloud Run/Functions, BigQuery/Firebase, and government/public data portals including IMD and ISRO/Bhuvan.

Judging weights: Problem-Solution Fit 20%; AI/Technical Execution 25%; Depth & Reach Across India 20%; Impact Potential 15%; Deployability & Scalability 20%.

Submission package listed: (1) source code in public or access-granted GitHub repo, (2) 3–5 minute demo video, (3) 10–12 slide pitch deck covering problem, solution, AI, beneficiaries, deployability and India scale, (4) brief solution description of 2–3 lines, (5) deployed prototype link.

Timeline shown: registration and prototype submission phase close 2026-09-30; evaluation 2026-10-01 to 2026-10-15; Top 20 announcement 2026-10-16; virtual Demo Day 2026-10-23. The page also says in-person Demo Day is in October with date/venue TBA. Rules: mandatory Google AI; project should be built during event period (pre-existing work only if substantially extended); use original or properly licensed code; cross-border applicability including BRICS; judges' decisions final. No specific additional deliverable format, exact demo-video hosting service, or repository license requirement was stated on the page content reviewed.

This implementation is an original prototype created for this brief. It only partially meets the scientific/technical ambition: Gemini text explanation is implemented as optional, but GEE, live meteorology, Gemini multimodal, physically modeled surge/rainfall pathways, automated dispatch, a deployment and a recorded demo are not. These gaps are disclosed rather than simulated as working integrations.
